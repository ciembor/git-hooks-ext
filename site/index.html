Three steps

From install to event.

Use config-based hooks on Git 2.54+, or add --legacy on older versions.

  1. 01

    Enable the bridge

    git-hooks-ext install
  2. 02

    Add an event hook

    cat > .git/hooks/branch-created <<'SH'
#!/bin/sh
echo "created branch: $1"
SH
chmod +x .git/hooks/branch-created
  3. 03

    Create a branch

    git branch topic
created branch: topic
