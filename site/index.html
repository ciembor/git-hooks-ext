git-hooks-ext

0.1.0

Name

git-hooks-ext — semantic events for Git reference transactions

Synopsis

git-hooks-ext install [--local|--global|--system|--legacy]
git-hooks-ext add [--local|--global|--system] <event> <name> <command> [args...]
git-hooks-ext events
git-hooks-ext reference-transaction <state> [--dry-run]

Description

Git's reference-transaction hook reports old and new object IDs together with a ref name. git-hooks-ext translates that input into events such as branch-created, tag-deleted, and branch-renamed.

Git input 0000… a84f… refs/heads/topic
→
Event branch-created topic

Event hooks run after the transaction is committed. They receive the short ref name, full ref name, old object ID, and new object ID.

Events

Event names are identical in hook files, Git config, and dry-run output.

Quick start

1. Enable the hook bridge

# Git 2.54+
git-hooks-ext install

# Git 2.53 and older
git-hooks-ext install --legacy

2. Add an event hook

cat > .git/hooks/branch-created <<'SH'
#!/bin/sh
echo "created branch: $1"
SH
chmod +x .git/hooks/branch-created

3. Trigger it

git branch topic
created branch: topic

Notes

Rename detection is best-effort. A rename is emitted only when a deletion and creation have one unique object-ID match within the same ref namespace.

See Install for native packages and the README for complete hook arguments.
