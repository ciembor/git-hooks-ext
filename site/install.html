Install

0.3.0

Overview

Native packages install git-hooks-ext in your path. The commands below download version 0.3.0 and verify it before installation.

SHA256SUMS All release files

macOS with Homebrew

brew tap ciembor/git-hooks-ext
# Homebrew 7+ only
brew trust --formula ciembor/git-hooks-ext/git-hooks-ext
brew install ciembor/git-hooks-ext/git-hooks-ext

Debian and Ubuntu

Download: AMD64 .deb ARM64 .deb 

base=https://github.com/ciembor/git-hooks-ext/releases/download/v0.3.0
package="git-hooks-ext_0.3.0-1_$(dpkg --print-architecture).deb"
curl -fLO "$base/$package"
curl -fLO "$base/SHA256SUMS"
grep "  $package$" SHA256SUMS | sha256sum -c -
sudo apt install "./$package"

The standalone APK uses a release build key that is not installed as a trusted system key.

Container image

docker pull ghcr.io/ciembor/git-hooks-ext:0.3.0
docker run --rm ghcr.io/ciembor/git-hooks-ext:0.3.0 --version

The multi-platform image supports AMD64 and ARM64. Use a native package to install repository hooks on the host.

Enable hooks

After installing the native package, enable the bridge in each repository:

cd your-repository
git-hooks-ext install
# or: ghe install

The command automatically selects config-based hooks on Git 2.54+ and the legacy bridge on older versions. After upgrading Git, remove the legacy reference-transaction hook and run git-hooks-ext install again (or ghe install).

To remove the bridge, run git-hooks-ext uninstall. It preserves any reference-transaction hook that was not installed by git-hooks-ext.
